# NagisinnraLinux‑Mono
A lightweight Linux distribution based on Debian Trixie, designed with a pure monochrome and minimalist aesthetic.

NagisinnraLinux‑Mono is a special edition of the NagisinnraLinux project, rebuilt around the themes of black, white, gray, silence, and industrial minimalism.

While Mist Edition focuses on a “blue × wood × dark-room” atmosphere,  
Mono Edition pursues a world defined by monochrome, shadow, and simplicity.

---

## Features

### Monochrome-focused UI
- Black, white, and gray only  
- Flat design with no gradients or shadows  
- Ultra-thin window borders  
- Clean typography using Inter or Noto Sans

### Minimal and industrial desktop
- Wallpaper: black background with thin white lines  
- Icon theme: monochrome line-based icons  
- Terminal: black background, white text, gray cursor  
- Minimal UI elements for a quiet, distraction-free experience

### Lightweight performance
- ISO size: approximately 2.4GB  
- RAM usage: around 470MB  
- Based on Debian Trixie  
- fcitx5 + Mozc pre-installed  
- Fast even in virtual machines

---

## Technical Overview

- Base: Debian Trixie  
- Desktop Environment: Xfce4  
- Theme: Mono (GTK / Xfce / LightDM)
