# NagisinnraLinux‑Mono
**黒・白・灰の無機質な世界観に特化した、Debian Trixie ベースの軽量 Linux ディストリビューション**

NagisinnraLinux‑Mono は、本家 NagisinnraLinux をベースに  
「モノトーン」「無機質」「静寂」「硬質」をテーマとして再構築した特別版です。

Mist Edition が “青×木目×暗室” なら、  
Mono Edition は “黒×白×影×無機質” の世界観を追求しています。

---

## 特徴

### ■ モノトーン専用テーマ
- 黒・白・灰のみで構成された UI  
- 影・グラデーションを排除したフラットデザイン  
- ウィンドウ枠は極細ラインで構成  
- フォントは細字の *Inter / Noto Sans* を採用

### ■ 無機質なデスクトップ構成
- 壁紙は黒背景＋白の 1px ラインのみ  
- アイコンは線画ベースのモノトーン  
- ターミナルは黒背景＋白文字＋薄灰カーソル  
- 最小限の UI 要素で静寂な操作感

### ■ 軽量性は本家と同等
- ISO サイズ：約 2.4GB  
- RAM 使用量：約 470MB  
- Debian Trixie ベース  
- fcitx5 + Mozc 事前組み込み  
- 仮想環境でも高速動作

---

##  技術構成

- **Base**: Debian Trixie  
- **DE**: Xfce4  
- **Theme**: Mono (GTK / Xfce / LightDM)  
- **Panel**: Mono 専用 xdg  
- **Wallpaper**: モノトーン専用背景  
- **Initramfs**: Mono 起動テーマ反映済み  
- **Skel**: Mono 初期設定を完全適用
